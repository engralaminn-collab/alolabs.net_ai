# Link status — what is in the repo, what is partial, what is not

**Branch:** `arena/e6f38d2a-alolabs-net-ai` · **Date:** 2026-10-08
**Supersedes the verification log in** `docs/LINK-COVERAGE-REPORT.md` where the two differ. That report was written
before several items were re-checked; its test counts and some "Ported" labels were not re-run in this round.

This document answers one question per link: is the element in the project, partly in it, or not in it.
Every link below comes from the inventory in `docs/LINK-COVERAGE-REPORT.md` §3. If a link was in the original
request but is not in that inventory, it is not listed here, and it should be sent again.

Status words:

- **Ported**: the artifact exists in this repo and was checked by a test, a type check, or a render.
- **Partial**: some of the element exists; the gap is named in the notes.
- **Backlog**: not implemented. Relevant to the product, not started.
- **No port**: not applicable to this codebase (different runtime, CLI-only, or content only).
