## Technology Stack

| Layer | Technology | Notes |
|---|---|---|
| **Web Platform** | Next.js 16 + TypeScript + Prisma + Tailwind CSS | Current foundation |
| **Mobile** | Flutter (single codebase, native performance) | iOS + Android from one codebase |
| **AI** | Multi-model (Claude/GPT-4/Gemini) + local (Llama/Mistral) | Redundancy and cost optimization |
| **Database** | SQLite (dev) → PostgreSQL (production) | Seamless migration path |
| **Cache/Real-time** | Redis + Socket.io | Sub-2s response times |
| **Vector Store** | Qdrant/Weaviate for RAG | Enterprise knowledge retrieval |
| **Payments** | bKash, Nagad, SSLCommerz, Stripe | Bangladesh + international |
| **Auth** | NextAuth.js + MFA TOTP + OAuth | Enterprise-grade security |
| **Infrastructure** | Ubuntu 24.04 + PM2 + Nginx + Docker | Proven, battle-tested stack |

## Risk Assessment

| # | Risk | Probability | Impact | Mitigation |
|---|---|---|---|---|
| 1 | **AI API Costs Spiral** | Medium | High | Multi-model strategy (local + cloud), aggressive caching, fine-tuning local models for common tasks |
